# 네 번째 장 기획 — 돌산터널과 무지개정원의 배지

> 상태: **계획 / 미구현**, 작성일: 2026-10-01.
> 출발점: 오렌지배지(`thunder`)를 가진 기존 저장. 목표: 무지개시티의 민화에게 네 번째 배지 받기.
> 아래 지도·편성·보상은 이번 장의 제안 계약이다. 구현 확정값과 검증 결과는 작업 완료 시 갱신한다.

제작 계획: [M13~M15](MILESTONES.md#chapter4) · [E14~E16 / T56~T67](GITHUB_ISSUES.md#chapter4).

## 이야기와 진행

주제는 **길을 살피고, 부탁을 기억하고, 함께 가꾸기**다. 기존 세 번째 장의 관동 지역 흐름을 이어 가되, 저학년이 길을 잃지 않도록 동굴과 도시를 짧게 구성한다.

**오렌지배지 → 블루시티 동쪽 → 9·10번도로 → 돌산터널 → 보라타운 → 8번도로·서쪽 지하통로·7번도로 → 무지개정원 → 누적 도장 16개 → 민화 → 무지개배지**

1. **갈색시티에서 다음 길 안내.** 마티스의 마무리 전화와 표지판이 블루시티 동쪽 산길을 알려 준다. 기존 6번도로·남북 지하통로·5번도로로 블루시티에 돌아간다. 오렌지배지만 있으면 `chapter3_complete` 없는 저장도 새 길을 이용한다. 새 안내는 완료 후 한 번 기록하고, 이전 배지 연출의 중단 복구는 유지한다.
2. **돌산터널 통과.** 9번도로와 10번도로 북쪽을 지나 동굴 두 층을 탐험한다. 밝은 화면·방향 표지·쉼터·고정 길을 사용한다. 플래시·풀베기·바위밀기·특정 포켓몬·시간 제한은 없다. 산길과 동굴의 트레이너는 선택이다. 남쪽 10번도로는 동굴을 거쳐야만 닿도록 분리한다.
3. **보라타운의 소개 편지.** 정원사가 무지개시티의 친구를 도와 달라고 부탁한다. 대화하면 소개 편지 플래그를 받는다. 도시와 서쪽 길은 편지 없이도 탐험할 수 있고, 무지개정원에서는 편지를 받는 위치를 안내한다. 포켓몬타워 내부와 유령 사건은 다음 장 후보로 남긴다.
4. **무지개정원의 씨앗상자.** 정원사가 로켓단에게 빼앗긴 씨앗상자를 되찾아 달라고 한다. 소개 편지가 있으면 로켓단과 필수 대결을 할 수 있다. 승리 뒤 상자를 회수하고 정원사에게 돌려주면 체육관이 열린다. 편지·상자는 가방 아이템이 아닌 사건 플래그다. 승리 직후 종료해도 전투 승리 기록으로 회수 상태를 복구한다. 반환의 별도 소모품·용돈 보상은 없고, 로켓단 전투 용돈만 한 번 받는다.
5. **민화와 네 번째 배지.** 관장 대결에는 정원 도움 완료, 회색·블루·오렌지배지, 누적 도장 16개가 필요하다. 수련생은 선택이며 체육관은 고정 통로다. 승리하면 무지개배지(`rainbow`)와 ₩2,500을 한 번 받는다.
6. **장 마무리.** 오박사가 축하하고 기존 지역을 자유롭게 왕복하도록 안내한다. 다음 지역은 준비 중이다. 게임코너·로켓단 아지트·실프스코프·잠만보·노랑시티·연분홍시티는 이번 범위에 넣지 않는다.

대사 예시: “밝은 표지판을 따라가 보자.”, “씨앗상자를 정원사에게 돌려주렴.”, “공부 도장이 {현재}개구나. 16개를 모으면 함께 도전해 보자!”

## 지역과 연결 계약

새 **15개 맵, 총 53개 맵**을 목표로 한다. 블루시티 동쪽 출구만 기존 지도에 추가한다. 문·사다리·출구의 정확한 타일 좌표와 도착 방향, 회복 좌표는 [T56](GITHUB_ISSUES.md#t56)에서 실제 지도와 함께 확정한다.

| 구간 | 새 MapId | 수 |
|---|---|---:|
| 블루시티 동쪽 ↔ 산길 ↔ 동굴 ↔ 남쪽 산길 | `route9`, `route10_north`, `rock_tunnel_1f`, `rock_tunnel_b1f`, `route10_south` | 5 |
| 보라타운과 센터 | `lavender`, `lavender_center` | 2 |
| 보라타운 서쪽 ↔ 무지개시티 동쪽 | `route8`, `underground_path_west`, `route7` | 3 |
| 무지개시티·센터·상점·정원·체육관 | `celadon`, `celadon_center`, `celadon_mart`, `celadon_garden`, `celadon_gym` | 5 |

- 연결 순서: `cerulean ↔ route9 ↔ route10_north ↔ rock_tunnel_1f ↔ rock_tunnel_b1f ↔ route10_south ↔ lavender ↔ route8 ↔ underground_path_west ↔ route7 ↔ celadon`. 동굴 출입과 층간 이동은 워프, 도로·도시는 기존 출구 계약을 사용한다. 모두 역방향으로 돌아올 수 있어야 한다.
- 10번도로 북/남은 별도 MapId로 분리하되 `route10` AreaId를 공유한다. 동굴 두 층도 `rock_tunnel` AreaId를 공유한다. 기존 `underground_path`는 남북 통로로 그대로 유지한다.
- 새 AreaId 8개: `route9`, `route10`, `rock_tunnel`, `lavender`, `route8`, `route7`, `celadon`, `celadon_garden`. 실내는 AreaId를 불필요하게 지정하지 않는다. 도시·정원에서 의도하지 않은 야생 전투를 만들지 않는다.
- 회복 지점: 10번도로 북쪽 안내원, 동굴 쉼터, 보라타운 센터, 무지개시티 센터. 회복 시 `lastHeal`을 보행 가능한 위치로 저장한다. 소개 편지·사건 완료 전에도 회복할 수 있다.
- 센터·PC·학습 게시판·상점은 공용 기능을 사용한다. 보라타운 상점은 별도 추가하지 않고 무지개상점은 단층으로 둔다.

## 학습·전투·아트

누적 도장 16개는 기존 `g.learn.stage()` 값이다. 세 번째 배지 뒤 16개를 추가 요구하지 않는다. 한 과목 설정·보호자 시작 진도·현재 학습 난이도를 인정한다. 날짜 변경과 하루 목표 완료로 사건을 차단하지 않는다.

| 상대 / ID | 조건 | 초기 편성 | 용돈 |
|---|---|---|---:|
| 산길 트레이너 / `route9_camper` | 선택 | 깨비참 Lv.20, 모래두지 Lv.20 | ₩400 |
| 동굴 등산가 / `rock_tunnel_hiker` | 선택 | 꼬마돌 Lv.21, 롱스톤 Lv.21 | ₩450 |
| 정원 로켓단 / `celadon_rocket` | 소개 편지 후 필수 | 주뱃 Lv.22, 슬리프 Lv.22 | ₩500 |
| 무지개체육관 수련생 / `celadon_trainee` | 선택 | 뚜벅쵸 Lv.23 | ₩450 |
| 민화 / `leader_erika` | 정원 도움 + 앞선 세 배지 + 도장 16개 | 덩쿠리 Lv.24, 우츠동 Lv.24, 라플레시아 Lv.26 | ₩2,500 |

야생의 기준 레벨은 산길·돌산터널 18~21, 서쪽 도로 19~22를 제안한다. 실제 레벨은 기존 `rollLevel`의 `floor(stage/10)` 가산을 포함한다. 도장별 tier·`obtainable === 'wild'`·낚시 필터를 유지한다. 숫자만으로 균형을 단정하지 않고 [T66](GITHUB_ISSUES.md#t66)에서 실제 문제 풀이로 확인한다.

민화 초상·필드 스프라이트·무지개배지 이미지와 manifest 항목만 필요한 만큼 추가한다. 기존 타일·NPC·음악을 재사용한다. 신규 포켓몬, 문제은행, 기술·상성 시스템, 별도 퀘스트 엔진은 이번 범위가 아니다.

|---|---|---|

- `MapId`·`AreaId`·맵 레지스트리·저장 `MAP_IDS`를 함께 추가한다. 기존 파티·박스·도장·배지·돈·위치를 초기화하지 않는다. 새 플래그는 기본 미진행으로 읽는다.
- 기존 오렌지배지 저장의 `badge_thunder` 보정과 마티스 연출 재개를 유지한다. `chapter3_complete`는 새 길 진입의 필수 조건이 아니다.
- `src/battle/index.ts`의 관장 조건은 현재 4/8/12개를 처리한다. `rainbow` 16개와 앞선 세 배지·정원 도움 검사를 공용 호출에 추가해 직접 호출로 우회하지 못하게 한다.
- `src/ui/screens/index.ts`의 `showBadge`는 알 수 없는 배지에 회색배지를 표시하므로, `rainbow` 이름·자산을 명시적으로 등록한다. 트레이너 카드에도 네 번째 배지를 추가한다.
- 패배·취소는 진행 완료로 취급하지 않는다. 전투 승리와 용돈·배지는 연출 전에 저장하고 재대화에서 중복 지급하지 않는다.
- 새 MapId 저장을 옛 버전이 읽으면 위치가 보정될 수 있다. 출시 후 문제 발생 시 신규 ID를 유지한 수정 배포를 우선하며, 이전 코드로 돌려야 한다면 위치·회복 호환 패치를 함께 준비한다. 사용자 저장 삭제로 해결하지 않는다.
