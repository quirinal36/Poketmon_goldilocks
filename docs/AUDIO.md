# 배경음악

게임의 새 배경음악 네 곡은 2026-09-30에 [Kie의 Suno 음악 생성 API](https://docs.kie.ai/suno-api/generate-music/)로 제작한 **가사 없는 연주곡**이다. `V6_MINI` 모델에 각 장면의 분위기·악기·템포를 설명하고, 기존 게임이나 상업 음악의 멜로디를 따르지 않도록 요청했다. 각 요청의 첫 번째 생성 결과를 선택했다.

| 파일 | 생성 제목 | 재생되는 곳 |
|---|---|---|
| `town.mp3` | Little Village Adventure | 타이틀·마을·도시·연구소·포켓몬센터 |
| `route.mp3` | Sunlit Road | 일반 도로 |
| `forest.mp3` | Green Forest Walk | 상록숲 |
| `battle.mp3` | Brave Little Challenge | 체육관·야생·트레이너·관장 전투 |

각 곡의 10~60초 구간을 사용하고, 앞쪽과 뒤쪽 2초를 교차해 48초 길이의 반복 파일로 만들었다. 파일마다 -22 LUFS를 목표로 음량을 맞추고 96kbps MP3로 저장했다. 실제 Kie 결과는 48초 지정에도 약 70~172초로 생성되어 게임용 길이로 편집했다.

게임은 같은 출처의 정적 파일을 불러와 기존 WebAudio 음악 버스에서 재생한다. 사용자의 음악 음량, 대사 읽어주기 중 음량 낮추기, 효과음과 배지·회복 징글은 기존 방식대로 동작한다. 파일 로드 또는 디코딩에 실패하면 해당 장면의 기존 칩튠을 재생한다. API 키는 제작 시에만 사용하며 게임 파일에는 포함되지 않는다.

음악 파일의 출처와 사용 조건은 [Kie 이용 약관](https://kie.ai/terms-of-use/)을 기준으로 배포 시 재확인한다. 약관에는 업로드한 사용자 콘텐츠의 소유권은 명시되어 있지만, API로 생성한 결과물의 상업적 배포 권한은 별도로 명시되어 있지 않다.
