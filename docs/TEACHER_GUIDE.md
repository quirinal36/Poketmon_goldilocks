# 포켓몬 공부 대모험 — 선생님·학부모 안내

## 시작과 조작

`npm install` 후 `npm run dev`로 실행하거나 배포된 게임 주소를 엽니다. 처음에는 **새로 시작**, 다음부터는 **이어서 하기**를 누릅니다. 모습과 이름을 고르고 오박사 연구소에서 첫 친구를 만납니다.

화면의 방향 버튼 또는 키보드 방향키로 이동합니다. **A / Enter / Z**는 대화·조사, **B / Escape / X**는 취소, **START / M**은 모험 메뉴입니다. 버튼은 터치하거나 Tab으로 이동해 Enter로 누를 수 있습니다. 물가에서 낚싯대를 가진 채 A를 누르면 낚시합니다.

전투에서 **싸운다**를 누르면 현재 학습 진도에 맞는 문제가 나옵니다. 정답이면 공격하고 오답이면 상대가 공격합니다. 야생 친구의 체력을 절반 이하로 낮추고 **몬스터볼** 문제를 맞히면 잡을 수 있습니다. 친구가 모두 지쳐도 최근 회복 장소로 돌아가 다시 시작합니다. 공부 도장 4개로 회색체육관의 웅에게, 회색배지와 누적 도장 8개로 블루시티의 이슬에게 도전할 수 있습니다. 첫 배지를 받으면 3번도로를 따라 달맞이산에 가서 연구원의 수첩을 찾아 주세요. 산 입구 연구원이 회복을 도와줍니다.

## 오늘의 공부와 진도

모험 메뉴의 **오늘의 공부**에서 수학·영어의 현재 레슨, 필요한 정답 수, 오늘 완료 여부를 확인합니다. **공부하기**로 전투 없이 문제를 풀 수 있고, 하루 목표를 끝내면 **복습하기**로 이어갑니다. 오답은 이후 복습에 다시 등장합니다.

수학은 1학년 1학기부터 2학년 2학기까지 23단원·146레슨입니다. 영어는 같은 네 학기 구간의 입문 과정 30단원·120레슨입니다. 초등 1~2학년 영어의 정규 국가 교육과정이라는 뜻은 아닙니다. 레슨마다 최소 20문제를 내장합니다. 문제를 반복해서 푸는 게임이며 정식 성취도 평가를 대신하지 않습니다.

## 보호자 메뉴

타이틀 또는 모험 메뉴에서 **보호자**를 누르고 화면의 곱셈에 답하면 열립니다. 이 확인은 아이의 실수 조작을 줄이는 장치이며 비밀번호 인증은 아닙니다.

- **하루 진도량**: 과목별 1·2·3레슨 또는 제한 없음. 기본은 과목별 1레슨입니다. 목표 이후에도 복습할 수 있습니다.
- **수학 사용 / 영어 사용**: 한 과목 이상 켜 두어야 합니다.
- **수학 / 영어 시작 진도**: 레슨 선택 후 **시작 진도 적용**을 누릅니다. 확인하면 앞선 레슨을 완료로 표시합니다. 실제 정답 기록을 만든다는 뜻은 아닙니다.
- **문제 읽어주기 / 대사 읽어주기**: 자동 음성을 조절합니다. 기기에서 제공하는 한국어·영어 음성을 사용합니다. 문제의 스피커 버튼으로 다시 듣고, 소리가 없으면 기기 음량과 음성 설치 상태를 확인합니다.
- **음악 음량 / 효과음 음량**: 배경 음악과 효과음을 따로 조절합니다.
- **학습 리포트**: 단원별 정답률, 연속 학습일, 최근 다시 볼 문제를 확인합니다.

**문제 미리보기**는 새 탭에서 열립니다. 과목·학기·단원·레슨을 골라 그림과 정답을 확인할 수 있습니다. 아이에게 보여 주는 문제 내용은 미리보기와 같은 내장 문제은행입니다. 온라인 문제 갱신이 설정된 경우 서버 문제를 우선 사용합니다.

## 저장과 기기 옮기기

모험은 20초마다 현재 브라우저에 자동 저장됩니다. 메뉴(☰ 또는 M)의 **저장하기**를 누르면 현재 위치, 포켓몬, 아이템, 배지, 학습 진행을 즉시 저장합니다. 카카오 또는 라운지 계정으로 로그인한 상태에서는 계정에도 바로 저장을 요청하며, 화면에서 기기·계정 각각의 저장 결과를 확인할 수 있습니다. 다시 접속하면 시작 화면의 마지막 저장 시간을 확인하고 **이어서 하기**를 누르세요. 브라우저 데이터 삭제·시크릿 창 종료·다른 브라우저 사용 시 이 저장이 유지되지 않을 수 있습니다. 저장 공간 오류가 나오면 보호자가 공간을 확인해 주세요.

현재 운영 서비스에서 로그인하지 않은 게스트는 기기에 저장합니다. 다른 기기에서도 같은 모험을 계속하려면 카카오 또는 라운지 계정으로 로그인하세요. 두 기기에서 동시에 같은 모험을 진행하지 마세요. 익명 로그인을 별도로 허용한 Supabase 프로젝트에서만 **이어하기 코드 만들기**를 사용할 수 있습니다. 6자리 코드는 한 번만 쓸 수 있고 7일 후 만료됩니다.

**저장 데이터 초기화**는 두 번 확인한 후 새 모험으로 바꿉니다. 이전 기록으로 되돌리는 기능은 없습니다.

## 배포 방식 차이

| 실행 방식 | 문제·게임 | 저장·이어하기 코드 |
|---|---|---|
| 설정 없는 웹 실행 또는 로그인 없는 게스트 | 내장 문제로 실행 | 기기 저장 |
| 카카오·라운지 계정으로 로그인한 운영 주소 | 내장 문제 + 서버 문제 갱신 | 기기·계정 저장 |

[라운지 게임 페이지](https://lounge.letscoding.kr/works/leco/poke)의 **Play**를 누르면 [운영 게임 주소](https://poke.letscoding.kr/)가 열립니다. ZIP 업로드는 사용하지 않습니다. 서비스 워커를 통한 인터넷 단절 상태의 재접속 기능은 제공하지 않습니다.

홈 화면 추가를 지원하는 브라우저에서는 **홈 화면에 추가**를 사용할 수 있습니다. 실제 기기의 설치 화면·음성은 브라우저에 따라 다릅니다. 배포 설정은 [DEPLOY.md](DEPLOY.md), 구현 및 검증 범위는 [VERIFICATION.md](VERIFICATION.md)를 참고하세요.
