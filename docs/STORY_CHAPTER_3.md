# 세 번째 장 기획 — 이수재의 부탁과 항구 도시의 배지

> 상태: **계획 / 미구현**, 작성일: 2026-10-01.
> 출발점: 블루배지(`cascade`)를 가진 기존 저장. 목표: 갈색시티의 마티스에게 세 번째 배지 받기.
> 기존 문서가 예고한 후속 지역을 바탕으로 작성한 이번 구현안이다. 아래 맵 구성·도장 조건·편성·보상은 새 기획이며 구현 결과가 아니다.

제작 계획: [M10~M12](MILESTONES.md#chapter3) · [E11~E13 / T44~T55](GITHUB_ISSUES.md#chapter3).

## 이야기와 진행

주제는 **친구의 이야기를 듣고, 하나씩 확인하고, 도움을 이어 주기**다.

**블루배지 → 금빛다리·25번도로 → 이수재 돕기·승선권 → 5번도로·지하통로·6번도로 → 갈색시티 → 상트앙느호 선장 돕기 → 누적 도장 12개 → 마티스 → 오렌지배지**

1. **블루시티에서 출발.** 오박사가 북쪽 이수재의 집을 알려 준다. 기존 `chapter2_complete` 여부와 관계없이 블루배지가 있으면 시작할 수 있다. 이슬의 기존 마무리 전화와 도시의 “이번 모험은 여기까지” 안내를 새 목적지로 바꾼다. 배지가 없으면 이슬을 안내하고 북쪽·남쪽 새 출구를 막는다.
2. **금빛다리와 이수재.** 24번도로의 다리를 지나 25번도로의 집으로 간다. 다리의 트레이너 대결은 선택이다. 연구 장치에 문제가 생긴 이수재가 표시등과 연결 장치를 차례로 확인해 달라고 부탁한다. 두 상호작용 후 이수재에게 돌아가면 감사 인사와 상트앙느호 승선권을 받는다. 제한 시간·정답 추측 퍼즐·5연속 강제 전투는 없다. 이수재는 회복도 도와준다.
3. **항구 도시로 이동.** 블루시티로 돌아와 5번도로 → 지하통로 → 6번도로 → 갈색시티로 이동한다. 승선권 없이도 도시에 도착할 수 있지만 선착장에서 이수재에게 가는 길을 안내한다. 센터·상점·공부 게시판은 기존 기능을 쓴다. 지하통로는 짧은 왕복 통로이며 노랑시티나 별도 관문 맵은 만들지 않는다.
4. **상트앙느호에서 도움 이어 주기.** 승선권이 있으면 도시 안 선착장에서 배로 들어간다. 갑판의 선원에게 선장을 위한 휴식 꾸러미를 받아 선장실에 전달한다. 선장은 포켓몬을 회복해 주고 갈색체육관에 갈 수 있도록 소개한다. 꾸러미·승선권·소개는 스토리 플래그로 기록한다. 배는 사건 후에도 정박해 있어 다시 들어갈 수 있다. 선상 라이벌 재대결은 선택이다.
5. **마티스와 세 번째 배지.** 체육관 입구는 선장 도움 완료 후 열린다. 관장 대결에는 회색·블루배지와 누적 도장 12개가 필요하다. 수련생 전투는 선택이며, 통로는 고정 경로로 만든다. 쓰레기통 스위치 추측이나 풀베기 기술·특정 포켓몬을 요구하지 않는다.
6. **장 마무리.** 마티스에게 이기면 오렌지배지(`thunder`)와 용돈 ₩2,000을 한 번 받는다. 오박사의 축하 뒤 기존 지역을 자유롭게 왕복한다. 다음 지역은 준비 중이라고 안내한다. 이번 장에서 11번도로·디그다의 굴·노랑시티는 열지 않는다.

대사 예시:

- 이수재: “표시등부터 살펴봐 주겠니? 하나씩 확인하면 괜찮아.”
- 선장: “고맙구나! 포켓몬들도 함께 쉬어 가렴. 체육관에 너희 이야기를 전해 둘게.”
- 마티스: “공부 도장이 {현재}개구나. 12개를 모으면 함께 겨뤄 보자!”
- 승리 후: “끝까지 차분하게 도전했구나! 오렌지배지를 받아 줘.”

## 지역 구성

기존 블루시티를 확장하고 **13개 맵을 추가해 총 38개**를 목표로 한다. 좌표는 T44에서 기존 건물·NPC·복귀 위치와 대조해 확정한다.

| 연결 | 맵 ID | 역할 |
|---|---|---|
| 블루시티 북쪽 ↔ 24번도로 ↔ 25번도로 ↔ 이수재의 집 | `route24`, `route25`, `bill_house` | 금빛다리, 선택 전투, 연구 장치, 승선권, 회복 |
| 블루시티 남쪽 ↔ 5번도로 ↔ 지하통로 ↔ 6번도로 ↔ 갈색시티 | `route5`, `underground_path`, `route6`, `vermilion` | 짧은 남행 경로와 항구 도시 |
| 갈색시티 ↔ 센터·상점·체육관 | `vermilion_center`, `vermilion_mart`, `vermilion_gym` | 회복·PC·학습·구매·세 번째 배지 |
| 도시 선착장 ↔ 선내 ↔ 갑판 / 선장실 | `ss_anne_1f`, `ss_anne_deck`, `ss_anne_captain` | 승선 확인, 꾸러미, 선택 라이벌, 선장 |

모든 출구·문·계단은 왕복한다. 회복 지점은 이수재의 집, 갈색시티 센터, 선장실이며 사건 전에도 선내에서 회복할 수 있는 NPC를 둔다. 정확한 회복 좌표와 기절 복귀 경로를 T44에 기록한다. 회복 NPC에 재방문해도 사건 보상을 반복하지 않는다.

## 학습·전투·보상

- 도장 12개는 기존과 동일한 **누적 완료 레슨 수**다. 두 번째 배지 후 12개를 추가로 요구하지 않는다. `g.learn.stage()`를 사용하고 보호자의 시작 진도·한 과목 사용을 그대로 인정한다.
- 도로·이수재·선박 사건은 추가 도장으로 막지 않는다. 하루 목표를 마쳤다면 저장 후 나중에 이어 할 수 있다. 복습으로 같은 도장을 중복 지급하지 않는다.
- 모든 전투 문제는 현재 학습 진도를 따른다. 지역에 맞춰 학년·과목·단원을 강제하지 않는다. 문제은행 확장은 이번 범위에 없다.
- 선택 전투를 모두 건너뛰어도 완료할 수 있다. 포켓몬 타입·기술 소유 조건은 없다.
- 전투 편성은 다음을 초기값으로 삼아 T54에서 기존 배틀 규칙으로 실제 확인한다. 야생 레벨은 북쪽 12~16, 남쪽 14~18을 초기 목표로 하되 기존 출현 필터와 도장별 해금 규칙을 유지한다.

| 상대 | 조건 | 초기 편성 | 용돈 |
|---|---|---|---|
| 금빛다리 트레이너 | 선택 | 구구 Lv.15, 모래두지 Lv.15 | ₩300 |
| 6번도로 트레이너 | 선택 | 꼬렛 Lv.16, 고라파덕 Lv.16 | ₩350 |
| 선상 라이벌 | 선택 | 기존 라이벌 상대 종 Lv.18, 피죤 Lv.17 | ₩400 |
| 갈색체육관 수련생 | 선택 | 코일 Lv.18 | ₩350 |
| 마티스 | 선장 도움 완료 + 회색·블루배지 + 도장 12개 | 찌리리공 Lv.18, 피카츄 Lv.18, 라이츄 Lv.21 | ₩2,000 |

승선권과 소개는 진행 권한이며 소모품·별도 가방 아이템을 추가하지 않는다. 마티스 용돈은 트레이너 보상 한 번이며 배지 연출에서 다시 주지 않는다. 신규 초상·선박 타일·오렌지배지 이미지는 필요한 자산만 추가하고 기존 아트·음악을 재사용한다.

## 진행 기록과 호환

새 기록은 기존 `flags`, `defeatedTrainers`, `player.badges`, `pos`, `lastHeal`을 사용한다. 별도 퀘스트 엔진·로그인·저장 시스템은 만들지 않는다.

| 기록 | 제안 ID | 저장 시점 |
|---|---|---|
| 새 장 안내 완료 | `chapter3_oak_called` | 안내 종료 |
| 이수재 부탁·장치 확인 | `bill_asked`, `bill_light_checked`, `bill_connection_checked` | 각 상호작용 완료 |
| 이수재 도움·승선 권한 | `bill_helped`, `ss_ticket_received` | 두 확인 뒤 이수재 대화, 권한과 완료를 함께 저장 |
| 선원 꾸러미 | `ss_parcel_received` | 갑판 선원과 대화 |
| 선장 도움·체육관 개방 | `captain_helped`, `vermilion_gym_open` | 전달 완료와 개방을 함께 저장 |
| 선택 전투 | `bridge_trainer`, `route6_trainer`, `rival_ss_anne`, `vermilion_trainee` | 기존 배틀 승리 처리 |
| 세 번째 배지·연출·마무리 | `leader_surge`, `badge_thunder`, `badge_thunder_shown`, `chapter3_complete` | 승리 저장 → 연출 → 마무리를 구분 |

- 새 플래그가 없는 기존 저장은 미진행으로 읽으며 이전 파티·배지·도장·위치를 보존한다. `chapter2_complete`가 없는 블루배지 저장도 진입 가능하다.
- `MapId`·`AreaId`·맵 레지스트리·`MAP_IDS`를 함께 갱신해 새 지역 저장이 태초마을로 잘못 초기화되지 않도록 한다.
- `src/battle/index.ts`의 공용 체육관 조건과 스토리의 안내 양쪽에서 마티스의 조건을 일치시킨다. 직접 배틀 호출로 우회할 수 없어야 한다.
- `src/ui/screens/index.ts`의 트레이너 카드와 `showBadge()`는 현재 회색·블루배지만 처리한다. 세 번째 배지 이름·이미지·대체 텍스트를 두 화면 모두 추가한다.
- 승리 기록과 용돈·배지 지급을 저장한 뒤 대사나 연출을 실행하는 기존 방식을 유지한다. 중간 종료 후에는 남은 안내만 재개한다.
- 패배하면 최근 유효 회복 장소로 돌아가고 사건·배지를 완료 처리하지 않는다. 로그인 전환·날짜 변경도 사건 기록을 되돌리지 않는다.

## 완료 기준과 이전 장의 미완료 항목

- [ ] 기존 블루배지 저장 → 이수재 → 갈색시티 → 선장 → 마티스 → 저장·재접속을 완료한다.
- [ ] 승선권 없음/있음, 선장 도움 전/후, 배지 부족, 도장 11/12/12 초과의 경계를 확인한다.
- [ ] 사건의 각 저장 지점과 배지 연출 전후 중단·재개, 패배·재도전, 재방문에서 보상 중복·진행 막힘이 없다.
- [ ] 새 지역 전체를 왕복하고 기존 두 장의 학습·포획·배지·로그인·계정 저장 회귀가 없다.
- [ ] 빌드·단위·맵·포켓몬·E2E 검사 및 5개 해상도·실기기 검증 결과를 기록한다.
- [ ] 운영 테스트 계정으로 저장·재접속을 확인하고 안내·라운지 소개를 실제 구현 범위에 맞춘다.
